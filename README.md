# Python Pre-Mock Project: Stone-Paper-Scissors

A menu-driven Stone-Paper-Scissors game developed for the Python Pre-Mock evaluation. 

## Project Features
* **Package Architecture:** Code is strictly separated into a menu-routing `main.py` and a functional `game_pkg/logic.py` module.
* **Infinite Loop Menu:** Implements `while True` for continuous user interaction until exit.
* **Randomized Logic:** Utilizes the `random` module for unpredictable computer choices.
* **Input Validation:** Handles invalid user choices gracefully to prevent crashes.

## Execution
Run `main.py` in the terminal to launch the interactive game menu.
